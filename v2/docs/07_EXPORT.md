# Этапы 9–10. Excel и PDF экспорт

## Excel (openpyxl)

Листы:
- Исходные данные
- Слои (полный расчёт + итоги)
- Материалы (спецификация, упаковки, закупка)
- Итоги
- Сравнение (опционально)
- Рекомендации (опционально)

Кнопка **Excel** на вкладке «Расчёт».

## PDF (reportlab)

Структура отчёта:
1. Титул (объект, заказчик, дата, №)
2. Условия эксплуатации
3. Состав системы и расчёт слоёв
4. Итоговые показатели
5. Сравнение (если передано)
6. Рекомендации (если переданы)
7. Ограничения и дисклеймер

Поддержка кириллицы через DejaVu Sans / Liberation / FreeSans.
Кнопка **PDF** на вкладке «Расчёт».
