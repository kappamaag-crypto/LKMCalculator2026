# Этап 8. GUI (PySide6)

Дата: 2026-09-08

## Реализовано

### Главное окно (`ui/main_window.py`)
- Вкладки: Расчёт | Рекомендации | Сравнение | База | Системы | История | Настройки
- Демо-материалы и демо-системы загружаются при старте
- Статус-бар с результатами
- Меню Файл / Справка

### Вкладка «Расчёт» (`ui/views/calculation_view.py`)
- Исходные данные объекта (площадь, элементы, заказчик)
- Условия эксплуатации (C-категория, долговечность, среда, температура)
- Добавление / удаление слоёв
- Таблица слоёв с результатами расчёта
- Кнопка «Демо-система» (Blank Universal + Finish)
- Валидация с сообщениями на русском
- Автопередача результата в «Сравнение»

### Вкладка «Рекомендации» (`ui/views/recommendation_view.py`)
- Ввод условий
- Подбор и ранжирование систем
- Список с score
- Детализация причин / предупреждений
- Дисклеймер

### Вкладка «Сравнение» (`ui/views/comparison_view.py`)
- Таблица показателей
- Подсветка min/max
- Легенда (самая дешёвая, лучший баланс)

### Стили (`ui/styles.py`)
Современный светлый профессиональный интерфейс.

## Запуск

```bash
cd lkm_calculator
pip install -r requirements.txt
python main.py
```

## Заглушки (следующие итерации)
