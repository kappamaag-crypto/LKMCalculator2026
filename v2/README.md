# Калькулятор ЛКМ / АКЗ v2.0

Профессиональное desktop-приложение для расчёта расхода лакокрасочных материалов и предварительного подбора систем антикоррозионной защиты (АКЗ).

## Возможности

- Расчёт многослойных систем (толщина, расход кг/л, стоимость, упаковки)
- Сравнение 2–10 систем с подсветкой лучших показателей
- Двухступенчатый подбор систем АКЗ (фильтр → score 0–100)
- Экспорт в Excel (многолистовый профессиональный отчёт)
- Валидация входных данных на русском языке
- Формулы 1:1 с исходным калькулятором (не изменены)

## Стек

- Python 3.12+
- PySide6 (GUI)
- SQLAlchemy 2.x (БД)
- openpyxl (Excel)
- pytest

## Установка и запуск

```bash
cd v2
pip install -r requirements.txt
python main.py
```

## Тесты

```bash
python -m pytest tests/ -v
```

## Структура

```
app/
  domain/           — формулы, модели, calculator, comparison, recommendation
  infrastructure/   — БД, Excel-экспорт, логирование
  services/         — application services
  ui/               — PySide6 GUI
tests/
docs/               — аудит, архитектура, этапы
```

## Важно

Рекомендации носят **предварительный** характер.  
Окончательный выбор системы АКЗ — по технической документации производителя, проектным требованиям и нормативным документам.
