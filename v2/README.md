# Калькулятор ЛКМ / АКЗ v2.0

Профессиональное desktop-приложение для расчёта расхода ЛКМ и подбора систем АКЗ.

## Запуск

```bash
cd v2
pip install -r requirements.txt
python main.py
```

## Тесты

```bash
python -m pytest tests/ -v
```

Формулы 1:1 со старым калькулятором. Рекомендации — предварительные.
