### Новый этап 5.5 — Excel-экспорт сравнения систем

**[В РАБОТЕ]**

Цель: Excel сравнения должен содержать полноценную инженерную таблицу, а не только названия систем и несколько итоговых значений.

Обязательные требования:

- все сравниваемые системы;
- поддержка 2, 3, 4 и более слоёв;
- отсутствие silent truncation;
- количество слоёв;
- общая DFT;
- теоретический и практический расход ЛКМ;
- расход разбавителя;
- стоимость руб/м² и стоимость объекта;
- для каждого слоя: материал, связующее, DFT, WFT, потери, разбавление, разбавитель, укрывистость, расход, стоимость;
- для отсутствующего слоя в более короткой системе выводится `—`;
- Excel не выполняет инженерные расчёты самостоятельно — используются значения `ComparisonResult` / `SystemCalculationResult`;
- не добавлять складские и закупочные показатели в инженерное сравнение.

Реализовано в `ExcelExporter._sheet_comparison()`.

Добавлены regression tests в `tests/test_comparison_excel_export.py` для 2/4/5-слойных систем и проверки отсутствия обрезания данных.
