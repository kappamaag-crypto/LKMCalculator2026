# Границы продукта v3.0

Этот документ фиксирует, что калькулятор считает, а что сознательно не входит в продукт.

## 1. Назначение

Калькулятор предназначен для инженерного расчёта расхода ЛКМ/разбавителя и стоимости системы покрытия, а также для предварительного сравнения и подбора систем АКЗ.

Расчёт выполняется для **1 м²** либо для непосредственно заданной площади объекта.

## 2. 2К-материалы — только справочно

Для 2К-материалов интерфейс показывает только доступную справочную информацию:

- компонент A;
- компонент B;
- соотношение A:B;
- основание соотношения — масса или объём;
- pot life / рабочее время;
- induction time / время выдержки после смешения;
- примечания и источник данных.

Калькулятор **не выполняет** расчёт количества компонентов A/B, комплектов, фасовки или закупочной потребности для 2К.

## 3. Что не является складским учётом

В продукт не входят:

- закупочная потребность;
- количество упаковок;
- остатки;
- резервы;
- партии;
- приходы и списания;
- складские движения;
- WMS/ERP-функции.

Фасовка материалов может существовать в исторической модели/данных для совместимости, но не является расчётной частью текущего пользовательского сценария.

## 4. Геометрия расчёта

Основной пользовательский сценарий использует площадь в м². Отдельные поля «количество элементов» и «площадь одного элемента» не требуются.

Для единичного инженерного расхода используется 1 м²; для объекта вводится фактическая расчётная площадь.

## 5. Условия нанесения

В пользовательском интерфейсе основного калькулятора отсутствует отдельный блок условий нанесения с:

- температурой воздуха;
- температурой поверхности;
- относительной влажностью;
- точкой росы;
- запасом до точки росы.

Глубокий технологический контроль (`TechnologyCheck`) не является целью продукта. Существующие внутренние поля и совместимость с более ранними версиями могут сохраняться, но они не должны превращаться в новый пользовательский сценарий без отдельного требования.

## 6. Инженерные данные

Для расчётного слоя обязательны критичные исходные данные, прежде всего плотность и сухой остаток по объёму. Неизвестное значение (`None`/`UNKNOWN`) не должно автоматически превращаться в ноль.

Если критичных данных недостаточно, расчёт блокируется с понятным сообщением.

## 7. Экспорт

Excel/PDF содержат исходные данные, параметры слоёв, DFT/WFT, расход ЛКМ и разбавителя, стоимость, дату расчёта и версию формул.

Экспорт не содержит закупочных, складских или остаточных ведомостей.

## 8. Предварительный подбор систем

Рекомендации работают по принципу **hard-filter → простой scoring**. Невыполнение жёсткого критерия не компенсируется баллами.

Рекомендация не заменяет проверку ТДС производителя, проектных требований и применимых нормативных документов.
