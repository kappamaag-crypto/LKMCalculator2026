# Этап 7. Recommendation Engine

Дата: 2026-09-08

## Алгоритм (двухступенчатый)

### Этап 1 — Жёсткий фильтр (`rules.py`)

Система **проходит** только если:

1. Есть хотя бы один слой
2. Категория коррозии совпадает (если задана)
3. Долговечность ≥ требуемой (если задана)
4. Тип поверхности совместим (если данные есть)
5. Среда совместима (если данные есть)
6. Температурный диапазон покрывает требуемый

При отсутствии данных в карточке системы:
- `require_corrosion=True` / `require_durability=True` → система **не проходит** + `insufficient_data`
- иначе — предупреждение, но не отсев

### Этап 2 — Scoring 0–100 (`scorer.py`)

Только среди прошедших фильтр.

| Критерий | Вес по умолчанию |
|----------|------------------|
| Общее соответствие условиям | 30 % |
| Категория коррозии | 20 % |
| Долговечность | 15 % |
| Температурный диапазон | 10 % |
| Совместимость слоёв | 10 % |
| Технологичность (кол-во слоёв) | 5 % |
| Стоимость | 10 % |

Веса настраиваются через `ScoreWeights` / `AppSettings`.
