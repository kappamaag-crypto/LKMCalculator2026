# Калькулятор ЛКМ / АКЗ v3.0

**Текущая инженерная версия проекта.**

Профессиональное desktop-приложение для расчёта расхода лакокрасочных материалов и предварительного подбора систем антикоррозионной защиты (АКЗ).

> **Важно по структуре репозитория:**
> - `upload/` — **текущая версия v3.0**, рабочий исходный код.
> - `v2/` — **архивная версия v2.0**, сохраняется для истории и сравнения.
> - Для запуска актуальной версии используйте `upload/main.py`.

## Возможности v3.0

- Расчёт многослойных систем: DFT/WFT, расход кг/л и стоимость
- Расчёт для 1 м² или непосредственно заданной площади объекта
- Учёт разбавления с указанием базы расчёта
- Раздельный учёт расхода основного материала и разбавителя
- Сравнение систем АКЗ с детализацией по слоям
- Предварительный подбор систем по принципу **соответствие → оценка**
- Инженерная валидация входных данных
- Экспорт расчётов в Excel и PDF
- История расчётов
- Отдельная вкладка технологической информации по 2К-материалам: компоненты A/B, соотношение, основание соотношения, pot life и induction time
- GUI на PySide6
- SQLAlchemy 2.x и SQLite
- Тесты на pytest

**Важно:** программа не является складской системой и не рассчитывает закупочную потребность, количество упаковок, остатки, партии, резервы или движения материалов.

**2К-материалы:** доступны как технологическая информация. Для них показываются компоненты A/B, соотношение смешивания и технологические времена, если они известны. Отдельный расчёт комплектов, закупки и складских остатков не используется.

## Установка и запуск

Из корня репозитория:

```bash
cd upload
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
python main.py
```

Или после первого запуска можно использовать готовый `.bat`-файл из корня репозитория.

## Тесты

cd upload
python -m pytest tests/ -v

## Инженерный подход

Расчётный контур v3.0 строится вокруг цепочки:

**Объект → поверхность → среда → ISO 12944 → система → слои → разбавление → DFT/WFT → потери → расход → стоимость → сравнение/документы**

Рекомендации носят **предварительный** характер. Окончательный выбор системы АКЗ выполняется по технической документации производителя, проектным требованиям и нормативным документам.

## Что намеренно отсутствует

- количество элементов и площадь элемента;
- закупочное количество;
- количество упаковок / комплектов;
- остатки и складские балансы;
- партии, резервы, приходы и списания;
- отдельный расчёт стоимости комплекта 2К;
- отдельный пользовательский блок условий нанесения с температурой, влажностью и точкой росы.
