# Recommendation Engine

Дата актуализации: 2026-09-09

## Назначение
Модуль выполняет предварительный подбор систем АКЗ. Он не заменяет проектную проверку и техническую документацию производителя.

## 1. Hard-filter
Сначала выполняются обязательные проверки. Система, не прошедшая обязательный фильтр, не может быть «спасена» scoring.

Проверяются:
- наличие слоёв;
- категория коррозии и требуемая долговечность;
- тип поверхности;
- среда;
- температурный диапазон;
- допустимость целевой DFT и технические ограничения материала.

При отсутствии критичных данных система получает статус `Недостаточно данных`, а не считается подходящей по умолчанию.

## 2. Scoring
Scoring применяется **только после hard-filter** и нужен только для простого ранжирования допустимых вариантов.

Используются четыре понятных фактора:

| Критерий | Вес по умолчанию |
|---|---:|
| Категория коррозии | 30 % |
| Долговечность | 25 % |
| Количество слоёв | 20 % |
| Стоимость | 25 % |

Стоимость неизвестна → она не считается нулевой и не используется как преимущество. Для неизвестной стоимости используется нейтральная оценка.

Не используются отдельные скрытые веса для условий нанесения, совместимости химии и других сложных экспертных метрик. Такие проверки остаются частью hard-filter/предупреждений там, где они уже предусмотрены системой.

## 3. Сравнение систем
Отдельный Comparison Engine показывает только проверяемые показатели:
- слои и материалы;
- DFT по каждому слою и общая DFT;
- расход ЛКМ;
- стоимость на м²;
- стоимость объекта.

Производные показатели типа «лучший баланс цена/защита» не рассчитываются.

## 4. Границы
- 2К — только справочная информация: A/B, соотношение, pot life, induction time.
- 2К-компоненты, комплекты и остатки не рассчитываются.
- Фасовка, закупка, резервы и партии не рассчитываются.
- Склад / WMS / ERP отсутствуют.
- Глубокий технологический контроль не является целью модуля.
- Отдельный пользовательский блок условий нанесения не является частью основного калькулятора.

## Дисклеймер
> Предварительный подбор системы АКЗ. Окончательный выбор необходимо подтвердить технической документацией производителя, проектными требованиями и применимыми нормативными документами.
