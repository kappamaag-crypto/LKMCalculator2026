# Калькулятор ЛКМ / АКЗ v3.0

**Текущая инженерная версия проекта.**

Desktop-приложение для расчёта расхода лакокрасочных материалов и предварительного подбора систем АКЗ.

## Основные возможности

- многослойный расчёт DFT/WFT;
- теоретический и практический расход ЛКМ в кг/л;
- разбавление с явным основанием расчёта;
- отдельный расход разбавителя;
- стоимость на м² и стоимость объекта;
- расчёт для 1 м² или непосредственно заданной площади;
- прозрачное сравнение систем по слоям, DFT, расходу и стоимости;
- предварительный подбор систем по принципу **hard-filter → простой scoring**;
- валидация критичных входных данных;
- Excel/PDF и история расчётов.

## Жёсткие правила расчёта

Для инженерного расчёта слоя обязательны:
- `density` — плотность, кг/л;
- `solids_by_volume_percent` — сухой остаток по объёму, %.

Если один из параметров отсутствует или некорректен, расчёт блокируется с понятным сообщением. Массовый сухой остаток не используется как молчаливая замена объёмному.

Промежуточное округление запрещено: расчёт выполняется на исходной точности, округление используется только при отображении/экспорте.

`UNKNOWN` / `None` не приравнивается к нулю. Например, неизвестная цена не означает бесплатный материал.

## Границы продукта

Программа **не является складской системой** и не считает:
- закупочную потребность;
- количество упаковок;
- остатки;
- резервы;
- партии;
- приходы/расходы склада;
- WMS/ERP-показатели.

Количество элементов и площадь одного элемента также не используются: вводится непосредственно площадь расчёта.

### 2К-материалы

2К-вкладка является **только справочной**. Показываются, если данные известны:
- компонент A;
- компонент B;
- соотношение A:B;
- основание соотношения (масса/объём);
- pot life / рабочее время;
- induction time.

Расчёт компонентов, комплектов, фасовки, закупки или остатков для 2К не выполняется.

### Технологический контроль

Глубокий `TechnologyCheck` не является целью продукта. В основном калькуляторе нет отдельного блока условий нанесения с температурой, влажностью и точкой росы.

Рекомендации используют только необходимые инженерные hard-фильтры и простой понятный scoring; scoring не заменяет TDS производителя и проектную проверку.

## Запуск

```bash
cd upload
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
python main.py
```

## Тесты

```bash
cd upload
python -m pytest tests/ -v
```

## Версионирование расчётов

Версия формул фиксируется как `3.0`. Excel и PDF должны содержать версию формул, дату расчёта и исходные данные. История сохраняет снимок расчёта.

Рекомендации являются предварительными. Окончательный выбор системы АКЗ выполняется по технической документации производителя, проектным требованиям и применимым нормативным документам.
